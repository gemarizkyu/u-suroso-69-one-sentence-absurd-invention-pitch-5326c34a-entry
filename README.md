A one-sentence pitch for a ridiculous invention that fixes a tiny everyday annoyance: a toaster that launches your bread on a tiny parachute, then files a flight plan so it lands butter-side up every single time.

## The pitch

> A toaster that launches your bread on a tiny parachute, then files a flight plan so it lands butter-side up every single time.

The annoyance: toast always lands butter-side down. The fix: give every slice its own parachute and a filed flight plan, so physics has no say in the matter.

## Run it

```sh
python3 main.py
```

The program writes the pitch to `/output/entry.txt` (one sentence, 126 characters, well under the 220-character cap). It is fully deterministic: no model calls, no clock, no randomness, no input data.
